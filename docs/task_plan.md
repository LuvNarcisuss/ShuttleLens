## Key Questions

1. 如何在本地单进程中安全串行执行长时 CV 分析？
2. 如何保证任务和结果资源只能被任务所有者读取？
3. 如何在原生小程序中实现四点球场标注和状态轮询？

## Decisions Made

| Decision | Rationale |
|----------|-----------|
| 单线程进程内任务执行器 | 本地开发无需引入 Redis/Celery，且避免 GPU 并发竞争。 |
| 数据库存储任务记录，内存保存运行状态 | 支持个人历史列表，同时明确重启会中断运行任务。 |
| 首页与个人使用原生 tabBar | 满足固定双标签导航并符合小程序主包约束。 |
| 后端与小程序分七项交付 | 数据模型、服务、路由、迁移、导航、页面与验证均有独立测试门槛。 |
